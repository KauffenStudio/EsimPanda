# eSIM Panda — SEO Keyword Strategy (Competitive-Advantage Focus)

_Researched 2026-06-20. Goal: find keyword spaces where a small brand can realistically
rank, instead of fighting Airalo / Holafly / Saily head-on for "best esim"._

## Competitive landscape (what NOT to chase head-on)

| SERP | Who owns it | Verdict |
|------|-------------|---------|
| `best esim` / `best esim for travel` | Affiliate blogs (TechRadar, Nomadic Matt, weseektravel, eSIMDB, Tech Advisor) | ❌ Brand sites rarely rank — skip as primary target |
| `esim [country]` | Airalo, Holafly, Saily + aggregators (mybestsim, traveltomtom) | ⚠️ Competitive but we already have programmatic pages — keep grinding long-tail |
| `cheap esim` | Saily, Jetpac, TextNow (free tier) | ⚠️ Price leaders entrenched; use as secondary angle only |

## Where Panda can actually win (priority order)

### Tier 1 — Bottom-funnel comparison / "alternative" (HIGHEST ROI)
Buyers comparing providers, ready to purchase. Big players don't optimise for their own
"alternative" — easy gap. Build dedicated pages.
- `airalo alternative`, `holafly alternative`, `saily alternative`
- `cheaper than airalo`, `cheaper than holafly`
- `esim panda vs airalo` / `vs holafly` (own our brand comparisons)
- `esim vs roaming` (localise per market: MEO / NOS / Vodafone roaming for PT)

**Pain points to exploit** (from reddit/review research): Airalo top-up failures after 30
days, refund/support complaints, reliability. Frame comparison pages around these.

### Tier 2 — Differentiator / feature keywords (HOMEPAGE owns these)
Match Panda's real USP (instant, <2 min, affordable, keep-your-number). Competitors using the
same angle are small (Simbye, ETravelSim) — winnable.
- `instant esim`, `esim instant delivery`, `buy esim online instant`
- `esim ready in 2 minutes`, `esim qr code by email`
- `affordable travel esim`, `travel esim data plan`
- `esim keep your number` / dual-SIM angle (evergreen, true)

> ⚠️ Do NOT target "no app needed" / "esim without app" — Panda has iOS/Android apps
> (and more coming). Messaging must stay app-agnostic / app-positive, not anti-app.

### Tier 3 — Long-tail destination + use case (programmatic — already strong)
Extend the `/esim/[slug]` template.
- `esim for [country] tourists`, `esim for [country] from [home country]`
- `esim [city]` (city-level pages), `best esim for [region] trip`
- Deepen per-page FAQ (already have FAQPage schema — add more Q&A).

### Tier 4 — Multilingual edge (UNDER-EXPLOITED MOAT)
Panda ships 6 locales; most small competitors are English-only. Non-English SERMs are far
less saturated.
- 🇵🇹 PT: `esim para viajar`, `esim Portugal`, `cartão esim viagem`, `internet no
  estrangeiro sem roaming`, `chip internacional` (note: BR-heavy — target PT-from-Portugal)
- 🇪🇸 ES: `esim para viajar barato`, `tarjeta esim internacional`, `esim viaje`
- 🇫🇷 FR: `esim voyage`, `forfait esim international`, `esim pas cher voyage`
- Holafly dominates ES; PT/FR are weaker → biggest opening.

### Tier 5 — Informational / how-to (blog hub — top-funnel + internal linking)
Supports topical authority and feeds links to money pages.
- `how to install esim on iphone` / `on android`
- `what is an esim`, `does my phone support esim`
- `esim qr code not working`, `how to set up esim before travel`

## Implementation priorities
1. **Homepage** (this task): own Tier 2 + brand. Hub that links to destinations + comparisons.
2. **Comparison pages** (next): Tier 1 — highest commercial ROI.
3. **Blog/help hub** (later): Tier 5 — authority + internal links.
4. **City/region pages** (later): extend Tier 3 programmatic template.
5. Keep pushing locale content (Tier 4) — cheapest differentiation we have.

## Caveat
WebSearch can't return exact volumes/KD. Before committing to comparison/blog pages, validate
the shortlist in Ahrefs/Semrush/Google Keyword Planner (volume + difficulty) to prioritise.
